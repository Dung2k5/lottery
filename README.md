# webXoSo — Nền Tảng Xổ Số Trực Tuyến

Website tra cứu kết quả xổ số Việt Nam chính thức, chạy trên VPS riêng.

## 🛠️ Stack Công Nghệ
* **Frontend:** Next.js (Website tra cứu + Admin Dashboard)
* **Backend:** NestJS (API chính + Worker cào dữ liệu tự động)
* **Database & Cache:** PostgreSQL, Redis (Chạy qua Docker trên VPS)
